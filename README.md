# Responsive Mini Blog Card

A clean, minimal blog preview card component built with pure HTML & CSS. The card displays a featured image, a category badge, a title, a short excerpt and an author footer with a divider — centered on a soft background with a gentle shadow. A Frontend Mentor–style component challenge.

## ✨ Features

- 🖼️ Featured image with rounded corners
- 🏷️ Purple pill **category badge** ("Design")
- ✍️ Title, excerpt and author name separated by a subtle divider line
- 🎯 Perfectly centered layout using Flexbox on a full-viewport page
- 🎨 Soft, layered drop shadow for a floating-card feel
- 🔤 Sora Google Font for modern typography

## 🛠️ Tech Stack

- **HTML5** — semantic card markup
- **CSS3** — Flexbox, pseudo-elements & shadows
- **Google Fonts — Sora** — typography

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/shena9y/responsive-mini-blog-card.git
   ```
2. Open `index.html` in your browser — no build step required.
